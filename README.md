# AIS_supermarket

How to set up

1. use Intelij Idea Ultimate
2. clone project to your computer https://github.com/Inez-git/AIS_supermarket
3. edit configurations -> add configration -> Tomcat server -> Local
4. create new connection in MySQL Workbench -> File -> Open SQLScript -> db_supermarket
5. update database properties (user, password ...) in src/main/java...
6. run
